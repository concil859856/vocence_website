This is a sample page demonstrating the Vocence agent widget. The floating mic button in the bottom-right is the embedded agent — click it to start a conversation.

To add the widget to your own site, paste these two lines anywhere in your HTML: 

<script src="/dist/widget.iife.js" defer></script>
<vocence-agent
  agent-id="ag_demo"
  embed-token="vet_replace_with_your_token"
  server="http://localhost:8080">
</vocence-agent>

Generate your own embed token from the Vocence Studio agent settings page. Sessions opened via the token bill against the agent owner’s account — your visitors don’t need to sign in.
